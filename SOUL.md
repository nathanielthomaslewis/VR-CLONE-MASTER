# Soul — VR-CLONE-MASTER

## Vision

Produce **original** SideQuest / Meta Quest / Steam Frame MVP build prompts inspired by proven VR genre loops. This repo is a prompt + design vault — not a clone factory.

## Principles

1. **Original IP only** — cite commercial titles only as *genre inspiration* in internal docs. Shipping strings, store listings, characters, maps, audio, and UI marks must be original.
2. **Comfort first** — teleport + snap default; smooth locomotion opt-in; seated support; vignette; never ship sickness for spectacle.
3. **OpenXR-first** — prefer Godot 4 OpenXR (or Unity/Unreal OpenXR) over Meta-only plugins for Steam Frame + Quest dual targeting.
4. **MVP honesty** — each title folder scopes a *working level* + *full UI*, not a live-service clone.
5. **Shared stacks where real** — driving titles share vehicle / race UI assets under `shared-assets/vehicles/`. Combat titles do **not** fake-share FPS and physics-melee systems.
6. **Codex pick = success path** — `codex-vr-prompt/` deep-dives the highest-potential title (Riftsteel Arena) for App Lab, SideQuest, Steam Frame, and optional PC VR.

## What we are not

- We do not rip assets, maps, or audio from commercial games.
- We do not ship trademarked names in product UI.
- We do not commit store credentials or signing keys.
